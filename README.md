# Snatch

A modern full-stack web application built using React, Vite, Tailwind CSS, Node.js, and Express.js.

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js

## Installation

### Clone the repository

```bash
git clone https://github.com/avinash-2608/snatch.git
```

### Navigate to the project directory

```bash
cd snatch
```

---

# Frontend Setup

Install frontend dependencies:

```bash
npm install
```

Run the frontend:

```bash
npm run dev
```

---

# Backend Setup

Open a new terminal:

```bash
cd backend
```

Install backend dependencies:

```bash
npm install
```

Run the backend server:

```bash
node server.js
```

---

## Environment Variables

Create a `.env` file inside the `backend` folder.

Example:

```env
PORT=5000
```

Add your required API keys and database URLs inside the `.env` file.
